# Operations Docs

Use this folder for the current implemented runtime, operator workflow, and
artifact handling.

These docs describe what the repo can do today. They may mention manual
verification or external import steps where the current runtime still depends
on them for round close. Do not use this folder for forward planning or design
decisions.
