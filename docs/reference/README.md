# Reference Docs

Use this folder for tax references, oracle manifests, and deferred follow-up
material.

Nothing here should be treated as a normal runtime dependency unless another
document explicitly promotes it into an adopted checkpoint or boundary
workflow.

Small non-Markdown reference artifacts are allowed here when they are
documentation or oracle material rather than runtime inputs. The checked-in
CoinTracking export manifest CSV is intentional for that reason.
