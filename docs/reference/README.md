# Reference Docs

Use this folder for tax references, repo-safe oracle guidance, and deferred
follow-up material.

Nothing here should be treated as a normal runtime dependency unless another
document explicitly promotes it into an adopted checkpoint or boundary
workflow. Do not use this folder as the first stop for current runtime
behavior, roadmap sequencing, or architecture ownership.

Keep private oracle bundles and manifests in the external workspace, not in
the repo. This folder may describe oracle artifact families, but it should not
contain personal export inventories or captured report bundles.
